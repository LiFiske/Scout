About

Scout PDX

Scout PDX is a location-scouting tool for Portland, Oregon. It's built for the moment you know exactly what you need — a mossy stairwell for an indie film, a clean modern plaza for a graduation portrait, an industrial backlot, a rose garden — but you don't know where it is.

Instead of a short hand-picked list, Scout queries the full map of Portland and surfaces real, specific places that match what you describe, then pulls photographs of each one so you can judge a spot before you ever drive out to it.

How it works

You describe the location you need — a type, a setting, and a handful of keywords. Scout translates that into a live query against OpenStreetMap via the Overpass API, retrieving real tagged places across the city. For each candidate it searches Wikimedia Commons for geotagged photographs nearby, so what you see are openly-licensed pictures of the actual place. Locations and photos you like get saved into project folders you can return to.

Where it's going

Today, saved projects live in your browser. The natural growth path is a shared layer: user-contributed locations for spots the map doesn't know about, user-uploaded photos for places without street coverage, and community tags so scouts can describe locations in the language of a shoot, not just map data. Those turn Scout from a lookup tool into a living, scout-built database of where to film and shoot in Portland.
